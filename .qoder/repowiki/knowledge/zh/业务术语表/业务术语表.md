### 空间
- 定义：Multica 平台中的顶层组织单元，多个项目可归属于同一空间；每个空间的 `.repos/` 下维护一份共享的裸仓库缓存，任务环境根也按空间隔离。
- 别名：workspace

### 项目
- 定义：绑定到一个 git 仓库或本地目录的业务实体；可以是 `github_repo`（托管仓库）或 `local_directory`（直接指向本机目录）。项目资源决定任务运行时的工作树策略与并发限制。
- 别名：project、github_repo、local_directory

### 任务
- 定义：智能体在某个项目上的单次执行单元；每个任务拥有独立的 `{task-id}/workdir` 环境根，但共享同一项目的裸仓库缓存。同一 issue 的多轮复用同一个持久 workdir，不同任务之间互不干扰、可并行。
- 别名：task、issue task

### 智能体
- 定义：Multica 平台上配置的 Agent 定义，包含 Instructions、Skills、MCP 配置、模型与推理档位等；平台根据智能体配置 spawn Claude Code 并注入运行时上下文来执行业务任务。
- 别名：Agent、智能体设置

### 技能
- 定义：以 SKILL.md + scripts/references 形式组织的可复用能力包；Multica 将技能水合到 `{workDir}/.claude/skills/{slug}/`，由 Claude Code 原生扫描并按需加载，而非把全文拼入 prompt。支持 `disable-model-invocation` 控制是否向模型主动曝光。
- 别名：skill、SKILL.md

### brief（运行时简报）
- 定义：Multica 在每个任务的 `{workDir}/CLAUDE.md` 中注入的运行时上下文，用 `<!-- BEGIN MULTICA-RUNTIME -->` 标记包裹，包含 Agent Identity、CLI 用法、工作流、指令优先级、技能索引等；任务结束后按标记块精确还原原始文件。
- 别名：runtime brief、CLAUDE.md

### worktree
- 定义：从共享裸仓库缓存派生的独立工作副本；每个任务一个 worktree，挂在不同分支上，`.git` 仅为指针文件，避免重复 clone 大仓库。in_place 模式下直接操作真实目录，worktree 模式下在运行时目录内创建。
- 别名：git worktree、工作树

### sidecar
- 定义：任务运行时写入工作目录的辅助文件集合，包括 CLAUDE.md、`.claude/skills/`、`.multica/project/resources.json` 等；云端环境随 GC 整体删除，本地环境需逐字节还原/切除以保留用户真实编辑。
- 别名：sidecar files、侧车文件

### in_place
- 定义：本地目录项目的一种运行模式：直接在用户本机真实目录里修改代码，而非克隆到运行时目录；该模式一次只允许一个任务串行执行，后来者进入 `waiting_local_directory` 排队。
- 别名：in-place、原地模式

### 续跑
- 定义：同一 issue 的后续轮次复用上一次任务的持久 workdir，并通过 `PriorWorkDir` 传入；worktree 会滚到最新默认分支，会话仅在目录身份一致时保留，否则丢弃并注入续接提示。
- 别名：resume、续跑会话

### 渐进式加载
- 定义：Multica 对技能与大提示词的加载策略：仅 frontmatter 的 name+description 常驻上下文，正文与脚本文件在模型判断相关后才进入上下文；传输层按 SHA256 内容寻址缓存，避免重复搬运。
- 别名：progressive disclosure、按需加载

### MUL-*
- 定义：Multica 内部需求/改进单编号前缀（如 MUL-5529、MUL-5377、MUL-4297、MUL-5442），用于追踪与 prompt cache、技能精简、子 issue 编排等相关的设计决策。
- 别名：MUL ticket
