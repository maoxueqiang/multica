- 每个领域子目录通过 index.ts 聚合再导出，并在 package.json 的 exports 字段中显式声明子路径入口，形成稳定的对外 API 边界。
- 组件与其测试文件同名配对放置于同一目录（如 agent-detail-page.tsx 与 agent-detail-page.test.tsx），便于定位与维护。
- 国际化文案按 locale × namespace 的二维 JSON 组织，locales/index.ts 集中汇总为 RESOURCES 常量，新增语言或命名空间需在此同步注册。
- 弹窗通过 modals/registry.tsx 中的字符串 key switch 分发到具体 Dialog，新增弹窗需在 registry 中注册对应 case。
- 编辑器能力按 extensions/hooks/utils/styles 四层拆分，每个扩展单独成文件并附带 .test.ts 验证行为。
- 插件扩展通过 hooks（usePluginHookActions、usePluginModalSurfaces 等）收集宿主侧能力，再以 PluginPanelSection/PluginSurfaceFrame 等组件渲染，实现宿主与插件解耦。
