本模块是 web/desktop 共享的业务视图层，按领域划分目录（agents、chat、issues、inbox、autopilots、editor、settings、onboarding、modals、layout、navigation、i18n、locales、plugins、runtimes、skills、projects、dashboard、billing、auth、search、workspace、platform、各 IM 绑定页等），每个领域通过 index.ts 聚合导出，并在 package.json 的 exports 字段中显式声明子路径入口，供外部以 `@multica/views/<subpath>` 引用。

- 依赖方向严格单向：views → core + ui，不反向依赖；core 与 ui 保持互相独立。
- 路由/导航由 navigation 子包提供 NavigationProvider、AppLink、useIntentNavigate 等，解耦具体路由实现。
- 弹窗采用集中注册模式：modals/registry.tsx 通过 @multica/core/modals 的 useModalStore 读取当前 modal key 并 switch 渲染对应 Dialog，新增弹窗只需在 registry 中注册。
- 国际化集中在 locales/ 下按 locale(en/zh-Hans/ko/ja) × namespace(common/auth/issues/editor 等)组织 JSON，locales/index.ts 汇总为 RESOURCES 常量，i18n/ 提供 useT/useLocale/useTimeAgo 钩子。
- 编辑器基于 TipTap 3.27 构建，extensions/hooks/utils/styles 分层，支持 Markdown、Mermaid、代码块、附件、mention、slash command 等扩展。
- 插件体系通过 plugins/ 暴露 Hook 注入点（菜单、活动、MCP 审批、模态表面），通过 surface-bridge/surface-document 与宿主通信。
- 测试统一使用 Vitest + jsdom，配置在 vitest.config.ts，setup 文件位于 test/setup.ts，所有组件配套 .test.tsx/.test.ts。
