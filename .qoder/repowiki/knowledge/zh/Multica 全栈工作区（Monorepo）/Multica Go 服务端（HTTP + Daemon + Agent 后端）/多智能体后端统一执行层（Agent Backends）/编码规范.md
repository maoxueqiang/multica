- 每个智能体以独立 `<provider>.go` 文件实现 `Backend` 接口，并在 `agent.go` 的 `New()` switch 中按字符串协议族名分发构造。
- 所有进程创建必须经过 `Command.exec`/`execVia`/`runOwned` 等封装函数，禁止直接调用 `exec.CommandContext`，以确保进程组与 SIGKILL 清理策略一致。
- 平台相关逻辑通过 `_windows.go`/`_other.go`/`_unix_test.go` 等构建标签文件拆分，同一功能在不同 OS 提供不同实现或测试。
- 对自定义 runtime profile 的 fixed_args 一律通过 `filterLaunchPrefix` 按协议族黑名单过滤，禁止后端自行拼接可能覆盖协议标志的参数。
- 日志输出使用 `Config.logAgentCommand` 记录 argv，但通过 `redactAgentCommandArgs` 将所有非 flag 位置参数替换为 `<redacted>`，避免泄露敏感值。
- 流式读取统一使用 `newAgentStreamScanner` 创建的 `bufio.Scanner`，以 32 MiB 行上限防止单条事件撑爆内存。
