- Provider 差异化逻辑通过 switch on `params.Provider` 或 `skillsDirPath` 的 provider case 分发，新增 provider 需同时更新 skills 目录映射与 runtime config 路径表。
- 所有对 workdir 的写入都经 `recordWriteFile` / `recordMkdirAll` 登记到 `sidecarManifest`，并由 `CleanupSidecars` / `rollBackPreparedSidecars` 基于该清单做幂等回滚，禁止直接覆盖已存在路径。
- 用户可控字符串进入 agent 指令前必须经 `sanitizeNameForBriefMarkdown` / `sanitizeEmailForBrief` 等净化函数，防止 Markdown 注入。
- 平台相关实现拆分为 `_unix.go` / `_windows.go` 成对文件，包内其他代码通过相同函数名调用，屏蔽 OS 差异。
- 跨进程 Prepare/Reuse 使用私有 JSON 结构体（`preparationRequestPayload` 等）在父进程与 helper 间传递，敏感字段（如 OpenclawGateway token）通过方法集屏蔽 MarshalJSON。
- 工作目录布局遵循 `{WorkspacesRoot}/{workspace-slug-id}/{issue-slug-taskid}/` 的可读短段命名，并通过 `readablePathSegment` 截断超长标签并追加 UUID 随机尾以保证唯一性。
