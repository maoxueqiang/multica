- 对外暴露的公共函数（如 `Run/Output/CombinedOutput`、`Sync/SyncContext`、`CreateWorktree/CreateWorktreeContext`）成对提供带 context 的版本，以便传播取消与超时。
- 平台相关实现通过 Go build tag（`//go:build !windows` 与 `//go:build windows`）拆分为独立文件，共享同一 package 与接口签名。
- Git 子进程统一经由 `newGitCommand` 构造，固定设置工作目录为卷根、注入 `gitEnv()` 环境变量，并通过 `processtree` 执行以继承进程树管理能力。
- 对共享 bare repo 的并发访问通过 `sync.Map` 中 per-repo 的 `repoLock` 序列化，前台操作与后台 maintenance 使用同一把锁但具备抢占语义。
- 错误处理采用 `fmt.Errorf("...: %w", err)` 包装底层错误，并在超时场景将 `context.DeadlineExceeded` 转换为带超时报错的语义化错误。
- 长耗时操作（git fetch/clone/worktree）统一传入 `waitDelay`（5s）作为优雅停止后的强制终止等待期，避免僵尸进程残留。
