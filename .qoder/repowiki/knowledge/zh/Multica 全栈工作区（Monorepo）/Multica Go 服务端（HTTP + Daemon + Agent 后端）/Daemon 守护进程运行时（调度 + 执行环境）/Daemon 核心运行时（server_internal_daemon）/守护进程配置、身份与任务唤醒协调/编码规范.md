- 配置解析统一采用“CLI 覆盖 > 环境变量 > 默认值”三段式：先读 envOrDefault/durationFromEnv/intFromEnv，再判断 overrides 对应字段是否非零/非 nil 才覆盖。
- 所有可调超时/周期均以 `Default*` 常量声明在文件顶部，并通过 `MULTICA_*` 环境变量覆盖，便于部署侧按环境调整而不改代码。
- 对磁盘状态文件的写入一律采用“写临时文件 + chmod + os.Rename”的原子替换模式（见 `writeDaemonIDFile`），避免并发读取看到半写数据。
- WebSocket 连接管理遵循“单写 goroutine + 带缓冲 channel 队列 + 指数退避 + jitter”的模式，写失败时关闭连接并丢弃队列，防止重复 claim。
- 历史兼容逻辑通过独立的 `Legacy*` 函数（`LegacyDaemonIDs`、`LegacyDaemonUUIDs`、`promoteProfileDaemonID`）集中处理，并在当前 ID 上调用 `filterLegacyIDs` 去重，保证新旧身份平滑迁移。
- Agent 可执行文件解析区分“绝对/相对路径直接 canonicalize”和“裸命令名走 login shell 回退”，并对 `~/.multica/hooks` 目录做显式排除以避免钩子包装器递归。
