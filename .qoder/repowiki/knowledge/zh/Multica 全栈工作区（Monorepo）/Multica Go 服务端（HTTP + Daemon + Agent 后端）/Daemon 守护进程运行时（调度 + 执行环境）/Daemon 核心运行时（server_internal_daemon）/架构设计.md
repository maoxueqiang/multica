本模块以 `daemon.go` 中的守护进程实例为中心，将多个子模块按职责分层串联：
- 启动阶段由 `config_identity_wakeup_reconcile_gc` 加载配置、持久化机器身份并建立任务唤醒协调；同时通过 `agents_probe` / `agents_refresh` 扫描可用 Agent 二进制。
- 请求进入后，`skill_bundle_resolution` 按 provider 约定解析本地技能包，`repocache` 提供 bare clone 与工作树复用，二者共同构成任务的工作目录基础。
- `execenv` 在此基础上为每个任务注入隔离环境变量、会话存储、MCP 配置与 brief，并按 provider（Codex/Claude/Hermes/OpenClaw/Cursor/Reasonix/QwenPaw）差异化装配。
- 任务实际执行由 `processtree` 管理子进程组生命周期，配合 `runtime_lifecycle_mcp` 在任务内嵌 HTTP 代理转发 Remote MCP 调用。
- 所有能力通过 `wsrpc.go` 暴露为 wsrpc 方法，被上层 server/handler + service 消费；`gc.go`、`reconcile.go`、`wakeup.go` 等后台协程持续回收资源、同步状态。
跨子模块的契约集中在 `types.go`、`sidecar_manifest.go`、`runtime_config_*.go` 以及 execenv 中按 provider 命名的配置文件上，使不同 Agent 后端可共享同一套调度与清理流程。
