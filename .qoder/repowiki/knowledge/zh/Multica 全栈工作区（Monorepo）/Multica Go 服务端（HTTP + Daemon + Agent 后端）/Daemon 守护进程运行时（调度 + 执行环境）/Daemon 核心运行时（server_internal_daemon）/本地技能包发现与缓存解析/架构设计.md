模块由三个职责清晰的 Go 文件组成：
- `local_skills.go`：核心发现与加载层。通过 `localSkillRootsForProvider` 为每个运行时/provider（claude、copilot、opencode、codex、hermes、kimi、grok、qwen 等）计算优先级有序的 skill 根目录（provider-specific → ~/.agents/skills 通用根 → plugin 命名空间），再经 `enumerateLocalSkills` 递归遍历至 `maxLocalSkillDirDepth=4`，识别含 `SKILL.md` 的目录作为技能；`collectLocalSkillFiles` 在 walk 时做二进制/UTF-8/NUL 过滤并累计文件大小与数量上限（单文件 1MiB、总包 8MiB、文件数 256）。`loadRuntimeLocalSkillBundle` 以与 list 相同的优先级顺序解析同一 key，保证 list/load 一致性。
- `skill_cache.go`：基于磁盘的持久化缓存。`SkillBundleCache` 以 `workspaceID/source/id/hash` 四级安全路径存放 `bundle.json`，写入采用临时目录 + `os.Rename` 原子替换，并通过 `WithRefLock` 对相同 ref 加细粒度互斥锁；`validateSkillBundle` 用 `skillbundle.BuildManifest` 重新计算 hash 并与 ref 比对，确保缓存未篡改且与引用一致。
- `slash_skill.go`：轻量工具，使用正则从 Markdown 中提取 `[/label](slash://skill/<id>)` 形式的斜杠技能引用，去重后返回 `SlashSkillRef` 列表。
依赖方向单向向外：本模块依赖 `server/internal/skill`（frontmatter 解析）、`server/pkg/agent`（builtin runtime 描述）、`server/pkg/skillbundle`（manifest 构建），不被同层其他 daemon 子模块反向依赖。
