- provider 技能根目录通过 switch 分支集中声明，并按「provider-specific → ~/.agents/skills 通用根 → plugin」的固定优先级顺序组装，新增 provider 只需追加分支。
- 所有外部路径输入先经 `normalizeLocalSkillKey` / `safeSkillFilePath` / `safeCacheSegment` 等净化函数处理，拒绝绝对路径、`..`、空串及包含 NUL 的路径段。
- 文件收集阶段同时执行扩展名启发式（`IsLikelyBinaryFilePath`）与 UTF-8+NUL 双重校验，跳过无法安全 round-trip 的二进制内容。
- 资源限制以常量集中定义（`maxLocalSkillFileSize`、`maxLocalSkillBundleSize`、`maxLocalSkillFileCount`、`maxLocalSkillDirDepth`），并在 walk 过程中逐项计数与截断。
- 缓存写入采用「临时目录 + 原子 rename」模式，并在 rename 冲突时回退到删除旧目录重试，保证 bundle.json 的可见性不会部分更新。
- 并发访问通过 per-key 的 `sync.Mutex` 懒加载映射（`lockForKey`）实现细粒度互斥，避免全局大锁。
