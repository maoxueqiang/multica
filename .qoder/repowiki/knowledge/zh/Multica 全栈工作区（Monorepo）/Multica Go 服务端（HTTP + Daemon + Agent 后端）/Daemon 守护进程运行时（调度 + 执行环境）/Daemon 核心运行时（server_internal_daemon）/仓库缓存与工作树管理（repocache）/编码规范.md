- 每个对外方法都提供同名无参版本与 `...Context(ctx, ...)` 可取消版本，上下文取消会传播到锁等待与 git 子进程。
- 对同一 bare 仓库的所有写操作（clone/fetch/worktree add/ref update/maintenance）必须通过 `lockForRepo` 获取专属 `repoLock` 后再执行，不同仓库可并发。
- git 子进程统一经由 `runGit*` / `runGitOutput*` / `runGitCombinedOutput*` 系列函数发起，集中处理超时、工作目录与环境变量注入。
- 错误包装统一使用 `fmt.Errorf("...: %s: %w", strings.TrimSpace(string(out)), err)` 形式，保留 git 原始输出以便诊断。
- 对磁盘文件的原子写入采用 temp file + rename 模式（如 co-authored-by 状态文件、hook 文件），避免并发读取者看到半写内容。
- 通过 `isDaemonInstalledHook` 匹配注释标记识别 daemon 安装的 hook，确保只删除自身创建的钩子而不触碰用户或第三方 hook。
