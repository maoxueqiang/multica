- 多 provider 配置解析采用 switch(provider) 分支集中声明 {path, key, format} 三元组，新增 provider 只需扩展该分支而非散落逻辑。
- 对外暴露的 MCP 摘要类型（如 `runtimeLocalMcpServerSummary`）刻意不包含 URL、headers、command 或 env 等敏感字段，确保可安全离开本机。
- Remote MCP 代理对所有入站请求统一执行 size limit（`remoteMCPMaxRequestBytes`）、并发限流（semaphore channel）、调用计数上限与 JSON-RPC 错误码封装，避免裸透传。
- 工具白名单通过 `ApprovedTools` 列表进行名称匹配与 schema digest 比对，任何 schema drift 直接拒绝并返回专用错误码 `-32004`。
- HTTP 客户端方法统一通过 `postJSON`/`getJSON` 构造路径并附加 `X-Client-*` 身份头，能力集由 `daemonCommonCapabilities` 集中声明。
- 对旧版服务端的兼容性通过 404 检测后降级到 legacy 路径（如 workspace 列表、issue GC 检查），并用布尔标志位记录切换状态以避免反复探测。
