本模块由三个职责内聚的 Go 文件组成，均位于 `server/internal/daemon` 包下：
- `config.go`：集中定义 `Config`、`Overrides` 结构体与所有 `Default*` 常量；`LoadConfig(overrides)` 是单一入口，按“CLI 覆盖 > 环境变量 > 默认值”的优先级解析服务器地址、工作区根、GC/TTL 参数、各 Agent 超时与心跳间隔，并探测已安装的 Agent CLI（含 `~/.multica/hooks` 影子排除与登录 shell 回退），最终返回不可变配置。
- `identity.go`：维护机器级稳定身份——`EnsureDaemonID` 在 `~/.multica/daemon.id` 中持久化 UUID v7，首次调用时通过 `promoteProfileDaemonID` 将旧版 per-profile 布局迁移到机器级位置；`LegacyDaemonIDs` / `LegacyDaemonUUIDs` 生成历史 ID 集合供注册时合并旧 runtime 行；写操作使用临时文件 + `os.Rename` 原子落盘并以 `0600` 权限保护。
- `wakeup.go`：实现任务唤醒主循环 `taskWakeupLoop`，优先建立到 `/api/daemon/ws` 的认证 WebSocket 连接，发送 `daemon:heartbeat` 并接收 `EventDaemonTaskAvailable`、`EventDaemonPendingWork`、`EventDaemonRuntimeProfilesChanged` 等事件；连接断开后以指数退避（上限 30s）+ jitter 重试，同时保持 HTTP 轮询作为降级路径；通过 `runtimeSetCh` 感知运行时集合变化并触发重连。
依赖方向：三者同属 daemon 包内部协作，`wakeup.go` 消费 `config.go` 中的 `Config` 字段（如 `ServerBaseURL`、`HeartbeatInterval`），`identity.go` 被 `config.go` 在解析 `daemon_id` 时调用；对外仅暴露 `LoadConfig`、`EnsureDaemonID`、`ResolveWorkspacesRoot`、`ArtifactPatternsFromEnv` 等函数。
