模块以 `run.go` 中的 `Run`/`Output`/`CombinedOutput` 三个对外函数作为统一入口，内部通过 `newController` + `controller.interrupt/stop/finish/close` 四阶段钩子抽象平台差异：Unix 端（`controller_unix.go`）使用 `Setpgid=true` 创建进程组并通过 `syscall.Kill(-pid, SIGTERM/SIGKILL)` 向整个负 PID 组发送信号；Windows 端（`controller_windows.go`）通过 `CreateJobObject` + `AssignProcessToJobObject` 将子进程加入 Job Object，并以 `TerminateJobObject` 实现优雅与强制终止。`run` 协程在 `cmd.Wait()` 与 `ctx.Done()` 之间 select，先尝试 SIGTERM（Unix）或 Job 终止（Windows），等待 `gracefulStopTimeout` 后再升级为 SIGKILL/Terminate，最终通过 `finish` 轮询直到进程组完全消失（超时 5s）。调用方只需传入未启动的 `*exec.Cmd`，无需感知平台细节。
