- 通过 `//go:build` 标签在同一包内按平台拆分控制器实现，公共接口 `newController/interrupt/stop/finish/close` 保持签名一致。
- 所有平台相关错误在返回前用 `fmt.Errorf("...: %w", err)` 包装，保留原始错误链以便上层诊断。
- 资源清理采用 defer 模式：`controller.close()` 在入口处 defer 释放句柄，`finish()` 负责等待进程组彻底消亡并带超时轮询。
- 优雅退出遵循两步策略：先发送温和信号（SIGTERM / Job 终止），等待 `gracefulStopTimeout` 后再升级为强制信号（SIGKILL / TerminateJobObject）。
