- HTTP 处理器统一先调用 requireUserID/workspaceMember/parseUUIDOrBadRequest 做鉴权与参数校验，失败时通过 writeError 返回并立即 return。
- 时间窗口统一通过 parseSinceParamInTZ（带 N+1 日历日的日期分桶系列）与 parseExactSinceParamInTZ（无日期维度的排行榜系列）两种解析器区分，避免客户端裁剪导致的窗口不一致。
- 对受限 agent 的聚合响应使用泛型 foldRestrictedAgents[T, K] 配合 agentIDOf/rewrite/merge 三元函数，将不可见 agent 折叠到 restrictedAgentsRowID 并保持维度拆分（provider+model、failure_reason 等）。
- 需要跨并发请求幂等的资源创建（Mika 智能体、Mika 会话）均通过 SELECT pg_advisory_xact_lock(hashtextextended(...)) 串行化，并在持锁后二次检查已有记录。
- 多语言产品文案集中声明为 map[string]string（如 mikaOnboardingOpenings、mikaAgentDescriptions、mikaOnboardingLanguages），调用前显式校验 key 存在性再格式化。
- 用户可编辑文本一律经过长度上限与格式校验后再落库（如 patchOnboardingBodyLimit 16KiB、cloudWaitlistReasonMaxLen 500、email RFC 5321 校验），防止 JSONB 列被滥用。
