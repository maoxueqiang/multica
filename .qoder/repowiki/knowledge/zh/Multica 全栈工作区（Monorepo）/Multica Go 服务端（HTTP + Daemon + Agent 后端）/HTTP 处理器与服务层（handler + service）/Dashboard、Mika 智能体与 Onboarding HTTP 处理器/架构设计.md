本模块属于 server/internal/handler 包，按业务域拆分为四个文件：
- dashboard.go：实现六个只读 /api/dashboard/* 端点（usage/daily、usage/by-agent、agent-runtime、runtime/daily、failures/daily、failures/by-agent），统一通过 workspaceMember + optional project_id 鉴权，使用 parseSinceParamInTZ（N+1 日历日）或 parseExactSinceParamInTZ（精确 N 天）控制时间窗口；对含 agent 维度的响应通过泛型 foldRestrictedAgents[T] 将受限 agent 折叠到 __restricted_agents__ 桶中，保证 per-agent 汇总与 workspace 总量一致。
- mika_agent.go：CreateMikaAgent 通过 system_key=service.MikaSystemKey 在工作区内做幂等创建，使用 pg_advisory_xact_lock("mika:"+workspaceID) 串行化并发创建，并通过 LockWorkspaceForChatSessionCreate 保护会话创建；writeMikaAgentResponse 在事务外打开 or-create 会话并广播 EventAgentCreated。
- mika_onboarding.go + mika_onboarding_opening.go：StartMikaOnboarding 仅写入两条 chat_session_message（公开 opening 与隐藏 kickoff），不触发任务运行；kickoff 携带已发送的 opening 引用、语言、工作区名、时区与问卷答案，由 TaskService.OpenMikaOnboardingChat 在会话锁内去重；opening 文案以四语 map 存储，经 escapeMarkdownInline 转义后注入。
- onboarding.go + onboarding_shim.go：CompleteOnboarding 幂等翻转 onboarded_at 且仅首次触发 analytics.OnboardingCompleted；PatchOnboarding 维护 questionnaire JSONB，基于 before/after 状态差值一次性发射 onboarding_started/questionnaire_submitted/source_submitted 事件，并对 body 施加 16 KiB 限制；onboarding_shim.go 是 DEPRECATED 兼容层，保留 BootstrapOnboardingRuntime/NoRuntime 给 <v3 桌面端，注释明确禁止新增功能。
依赖方向单向向下：handler → service（TaskService、Entitlements）、pkg/db/generated（sqlc 查询）、internal/metrics/analytics、protocol（广播事件），不反向引用上层路由。
