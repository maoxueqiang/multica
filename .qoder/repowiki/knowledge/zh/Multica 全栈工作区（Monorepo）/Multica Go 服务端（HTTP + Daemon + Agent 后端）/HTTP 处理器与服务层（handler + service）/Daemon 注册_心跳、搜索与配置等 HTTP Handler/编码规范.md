- 所有 daemon 相关资源访问统一通过 `requireDaemonWorkspaceAccess` / `requireDaemonRuntimeAccess` / `requireDaemonTaskAccess` 系列辅助函数完成鉴权与 404/500 错误写入，避免在每个 handler 重复实现。
- HTTP 响应统一通过 `writeJSON` / `writeError` 助手返回，错误码集中由 handler 层决定，业务层仅返回 error。
- 数据库读写通过 `dbreader.Read` 选择器接入，daemon 工作区列表显式使用 `EventualConsistency` 策略声明最终一致性语义。
- 搜索类查询统一走 `runSearchQuery`，在只读事务内设置 `statement_timeout` 与 `transaction_read_only`，并将 SQLSTATE 57014 识别为超时而非通用 500。
- 对外能力协商通过请求头 `X-Client-Capabilities` 传递（如 `stable_attachment_urls`），服务端据此切换行为并保持向后兼容。
- 心跳更新采用可插拔调度器抽象 `HeartbeatScheduler`，测试用 Passthrough 直写 DB，生产用 Batched 批量合并以减少事务开销。
