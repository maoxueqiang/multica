本模块位于 `server/internal/handler` 包，围绕 `Handler` 结构体以文件为单位组织不同业务域：
- `daemon.go`：核心 daemon 生命周期（注册、心跳、任务 claim/finalize、批量 claim），通过 `requireDaemonWorkspaceAccess` / `requireDaemonRuntimeAccess` / `requireDaemonTaskAccess` 三组鉴权辅助函数统一校验 daemon token 或 PAT/JWT 的工作区/运行时/任务归属。
- `daemon_ws.go`：WebSocket 升级入口 `DaemonWebSocket`，调用 `buildDaemonWebSocketIdentity` 一次性加载 runtime 心跳租约并委派给 `daemonws.Hub`；`daemon_rpc.go` 通过 `rpcResponseCapture` 把 WS RPC 转发到现有 HTTP handler（如 `ClaimTasksByRuntime`），复用鉴权与响应逻辑。
- `daemon_workspace.go`：列出 daemon 可访问的工作区，区分用户 PAT/JWT 与 workspace-scoped daemon token 两种身份路径，并通过 ETag + If-None-Match 做缓存。
- `heartbeat_scheduler.go`：定义 `HeartbeatScheduler` 接口，提供 `PassthroughHeartbeatScheduler`（测试默认）与 `BatchedHeartbeatScheduler`（生产批量合并 UPDATE，按 tick 周期 flush 并处理 offline→online 恢复通知）两种实现。
- `search.go`：封装 `runSearchQuery`，在只读事务中 `SET LOCAL statement_timeout = 3s` 与 `transaction_read_only = on`，将 pg_bigm/pg_trgm 缺失导致的慢查询限制为 503，避免前端 spinner 卡死。
- `file.go`：附件上传/预览/下载，支持 CloudFront signed URL、S3 presign、proxy 三种模式，通过 `attachmentURLMode` 与 `ClientCapabilityStableAttachmentURLs` 能力头协商稳定 URL。
- `share_link.go`：工作区分享链接的创建、列举、撤销，使用部分唯一索引 `(workspace_id) WHERE is_active` 保证并发安全，并在事务内原子 deactivate 旧链接。
- `config.go`：公开 `/api/config`，读取环境变量（ALLOW_SIGNUP、GOOGLE_CLIENT_ID、MULTICA_*_URL、POSTHOG_* 等）并输出前端所需部署级开关，同时通过 `isOfficialCloudDeployment` 判断是否属于官方托管云以决定是否暴露 server_version。
依赖方向单向向下：handler → service/dbreader/queries/storage/middleware/auth，不反向依赖上层路由组装。
