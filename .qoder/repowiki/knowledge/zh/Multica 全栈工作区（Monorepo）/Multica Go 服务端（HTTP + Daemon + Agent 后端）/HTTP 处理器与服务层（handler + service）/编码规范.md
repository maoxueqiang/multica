- 每个资源域的 HTTP 端点拆分为独立文件（如 chat.go、issue.go、agent.go），但统一通过全局唯一的 `Handler` 实例访问 DB、Bus、Service 等共享依赖。
- 写操作完成后统一通过 `h.publish` / `h.publishTask` / `h.publishChat` 经 events.Bus 广播事件，再由 realtime.Hub 推送给订阅者，禁止 handler 直接调用 Hub。
- 工作区级权限校验使用 `requireWorkspaceMember` / `requireWorkspaceRole`，角色判断通过 `roleAllowed(role, roles...)` 白名单匹配。
- 请求参数校验统一走 `parseUUIDOrBadRequest` 等 helper，失败时写入带稳定 `code` 字段的 JSON 错误响应，而非裸 error。
- 第三方集成能力以 Handler 上的可选指针字段注入，未配置时对应 handler 返回 503，保证自托管部署可安全降级。
- 内置 Agent 指令与 SKILL.md 通过 go:embed 随二进制发布，由 service 层在运行时按需组装，不在创建时持久化到 agent.instructions。
