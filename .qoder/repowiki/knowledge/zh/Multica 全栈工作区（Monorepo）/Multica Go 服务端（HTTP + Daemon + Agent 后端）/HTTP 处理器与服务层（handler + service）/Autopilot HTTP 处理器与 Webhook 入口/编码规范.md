- HTTP 响应统一通过 `writeJSON` / `writeError` 助手函数输出，错误码与消息集中封装，避免直接调用 `w.Write`。
- UUID 与时间戳在 DB 模型与 JSON 之间转换时使用 `uuidToString` / `timestampToString` / `textToPtr` 等专用转换器，保持序列化一致性。
- 写操作进入事务后先执行锁（如 `LockSubscriberWrites`、`LockActiveMember`）再执行业务写入，并以 `defer tx.Rollback` 保证失败回滚。
- 对外返回的敏感字段（webhook_token、signing_secret）根据 `can_write` 权限动态裁剪，非授权调用方只能看到元数据。
- Webhook 入站采用「持久化优先」模式：先 INSERT `webhook_delivery`（queued），再异步派发，最终通过 `finaliseDeliveryTerminal` / `finaliseDeliveryWithRun` 回填状态与响应体。
- Provider 差异化逻辑通过 `provider` 字段（github/gitlab/bitbucket/gitea/generic）分发，未配置时默认 fallback 到 generic。
