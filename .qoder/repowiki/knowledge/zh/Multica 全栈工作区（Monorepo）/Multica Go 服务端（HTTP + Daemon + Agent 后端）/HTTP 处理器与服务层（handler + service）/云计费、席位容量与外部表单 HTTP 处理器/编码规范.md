- 所有入参 JSON 均通过 `http.MaxBytesReader` 设置 body 上限后再解码，防止恶意大请求耗尽内存。
- 公共/认证端点在解析参数后统一调用 `writeError` 返回结构化错误消息，而非直接写 status code。
- 需要工作区权限的端点通过 `requireCloudSubscriptionWorkspace` 集中完成成员角色与 workspace UUID 校验，再委派给统一的 `proxyCloudSubscription` 转发。
- 席位容量操作遵循“记录意图 → 调用 SeatCapacity → 根据决策标记 delivered/expired/failed”的四阶段 outbox 模式，并通过 workspace 级锁保证并发安全。
- 面向外部的表单（feedback、contact-sales）采用 DB-backed 的 per-user/per-email 小时级限流，而非进程内计数器。
- 对外暴露的枚举型字段（company_size、use_case、kind、source 等）使用本地白名单切片或 map 进行严格校验，未知值折叠为 “other”。
