本模块位于 `server/internal/handler` 包内，按资源维度拆分为多个文件：`project.go` 提供项目的 CRUD、搜索与批量资源关联；`workspace.go` 管理工作区生命周期、成员管理与复杂的删除清理流程（含分页任务清扫、锁超时与回滚重试）；`squad*.go` 覆盖小队的创建、成员管理、状态聚合与 Leader 评估记录；`source_context*.go` 处理源码上下文的捕获、预览、差异计算与流式上传；`workspace_mcp*.go` 暴露工作区 MCP 服务器库的管理接口。

所有处理器均挂载在统一的 `Handler` 结构体上，通过 `chi/v5` 路由解析 URL 参数，并依赖以下共享基础设施：`h.Queries`（由 `sqlc` 生成的 `pkg/db/generated` 访问层）、`h.TxStarter` 开启事务、`h.publish` 发布 `protocol.Event*` 实时事件、`h.MembershipCache` 失效成员缓存、`h.notifyDaemonWorkspacesChanged` 唤醒 daemon。权限统一通过 `requireUserID`、`requireWorkspaceRole`、`workspaceMember`、`canManageSquad`、`memberCanWireAgent` 等中间函数校验，错误一律经 `writeError` 写出标准 JSON 响应。数据库交互全部走 pgx/pgtype，枚举值在写入前预校验以避免把 DB CHECK 约束违规暴露为 500。
