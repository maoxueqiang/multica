本模块属于 server/internal/handler 包，按领域拆分为多个文件：chat.go（会话 CRUD）、chat_history.go（IM 通道历史读取，通过 ChatChannelHistoryReader 接口抽象 Slack/内置 transcript）、chat_title.go（LLM 异步生成标题）、chat_pinned_agent.go（快捷 Agent 钉选）、comment.go（评论树、折叠、摘要裁剪、@mention 触发）、reaction.go（表情反应）、pin.go（Issue/Project/View 钉选）。所有处理器均挂载在统一的 Handler 结构体上，通过 chi/v5 路由；请求经 requireUserID / ctxWorkspaceID / parseUUIDOrBadRequest 等通用校验后调用 h.Queries（由 sqlc 生成的 db 层）完成事务写入，并通过 h.publish / h.publishChat 向 protocol 事件总线广播实时变更。并发安全方面，会话创建使用 TxStarter 开启事务并显式对 workspace/project 行加 FOR KEY SHARE 锁，避免与删除工作区的最终清理竞态；标题生成走 detached goroutine + CAS UpdateChatSessionTitleIfCurrent 防覆盖。依赖方向单向向下：handler → service/middleware/util/db/generated/protocol/integrations/*，不反向引用上层。
