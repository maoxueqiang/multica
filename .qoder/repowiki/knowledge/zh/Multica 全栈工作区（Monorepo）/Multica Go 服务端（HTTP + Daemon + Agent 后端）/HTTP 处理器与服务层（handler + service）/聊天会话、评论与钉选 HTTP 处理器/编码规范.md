- 每个 HTTP 处理器以 (h *Handler) 方法形式实现，统一通过 requireUserID、ctxWorkspaceID、parseUUIDOrBadRequest 进行鉴权与参数校验，错误一律经 writeError 返回标准 JSON 响应。
- 数据库写操作优先使用 h.TxStarter.Begin 开启事务并在 defer 中 Rollback，必要时显式调用 LockWorkspaceForChatSessionCreate / LockProjectForChatSessionCreate 等专用 SQL 锁函数保证跨实体一致性。
- 写成功后通过 h.publish / h.publishChat 广播对应 protocol.Event* 事件（如 EventReactionAdded、EventPinCreated、EventChatSessionUpdated），使多客户端实时同步。
- DB 行到 JSON 的转换集中为 toResponse 辅助函数（如 commentToResponse、pinnedItemToResponse、reactionToResponse），统一处理 uuidToString/timestampToString 等类型转换。
- 对外响应结构大量使用指针字段（*string、*int、*bool）表达可选投影，仅在特定查询模式（如 summary=true、fold=true、include=view）下填充，保持默认响应形状向后兼容。
- 权限校验遵循“先解析 actorType/actorID，再调用 canInvokeAgent / accessibleAgentIDs / canReadIssueView”的固定顺序，确保 agent 调用、会话列表、钉选等场景都基于同一套可访问集合过滤结果。
