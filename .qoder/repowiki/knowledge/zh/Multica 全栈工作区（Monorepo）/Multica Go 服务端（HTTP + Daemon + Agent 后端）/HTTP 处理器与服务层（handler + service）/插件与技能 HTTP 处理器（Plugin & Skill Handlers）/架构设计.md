本模块位于 server/internal/handler，按功能拆分为多个文件：plugin.go 定义插件安装/列表/启停等管理端点及统一的 writePluginError 错误映射；plugin_action.go 实现插件 Action 桥接入口，通过 pluginCaller 区分 session 调用与插件 bearer token/callback token 调用，统一执行“安装存在且启用 → scope 授权 → 资源归属”三步校验；plugin_hook.go、plugin_agent_hook.go 处理事件/调度 Hook 回调；plugin_mcp.go 暴露 MCP 工具发现与管理员审批接口，并通过 ResolvePluginMCPCredential 在 daemon 连接时按需拉取凭据；plugin_surface.go 提供 iframe Surface 启动流程，使用 AES-GCM 密封短生命周期 launch token 并校验 Origin；plugin_package.go 负责插件包上传与版本管理；skill.go 集中定义 SkillResponse/SkillSummaryResponse/SkillFileMetadataResponse 等响应结构，并按需裁剪 SKILL.md 正文以避免大负载；skill_create.go、skill_import_archive.go、skill_refresh.go 分别封装创建、覆盖写入、归档导入、增量刷新等事务性写操作，统一通过 h.TxStarter.Begin + qtx.WithTx 保证原子性；mcp_overlay.go 提供 mergeMCPOverlay 纯函数，按 server name 合并 agent 保存的 mcp_config 与 per-task overlay，overlay 冲突时覆盖。依赖方向单向指向 internal/service（PluginService、Queries）、pkg/plugincontract、pkg/publicapi/v1、pkg/remotemcp 与 pkg/db/generated，handler 本身不持有业务状态，仅做参数解析、鉴权守卫、服务调用与响应序列化。
