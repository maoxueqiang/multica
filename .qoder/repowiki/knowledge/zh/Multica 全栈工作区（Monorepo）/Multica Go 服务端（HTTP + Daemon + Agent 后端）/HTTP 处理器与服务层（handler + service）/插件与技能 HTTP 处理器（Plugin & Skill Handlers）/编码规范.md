- 所有插件相关端点在入口处先调用 requirePluginsV1 / requirePluginActionV1 检查 feature flag，未启用时统一返回 ServiceUnavailable。
- service 层抛出的 *service.PluginError 通过 writePluginError 或 writePluginActionError 映射为具体的 HTTP 状态码与问题类型，handler 中禁止直接 string-match 错误消息。
- 写操作统一通过 h.TxStarter.Begin + qtx.WithTx 包裹，并在 defer 中 Rollback，仅在成功路径 Commit，避免部分写入。
- Skill 正文与文件内容在入库前一律经 sanitizeNullBytes（即 util.SanitizeTextForPostgres）清洗，防止 NUL/非法 UTF-8 进入 PostgreSQL TEXT 列。
- 对外响应结构按场景拆分（如 SkillResponse 含 content、SkillSummaryResponse 不含 content、SkillFileMetadataResponse 用 size/hash 替代 body），列表端点刻意省略大字段以降低网络负载。
- 插件 Action 调用通过 pluginCaller 统一判定 actor：session 路径走 X-User-ID + 安装头，Hook 路径走 mp*_callback_token 或安装 bearer token，再委派 AuthorizePluginAction 完成 scope 校验。
