- Service 通过构造函数接收 *db.Queries、TxStarter、Bus 等依赖，测试中可注入 fake 或 nil 以关闭可选能力（如 Entitlements、FeatureFlags）。
- 对外错误以包级 sentinal error（如 ErrActiveDuplicate、ErrParentIssueNotFound）+ 结构化 PluginErrorKind 表达，调用方据此映射 HTTP 状态码。
- 时间/调度相关函数统一接受 time.Time 参数并以 UTC 返回结果，避免应用时钟漂移影响分布式调度正确性。
- 内置技能与 Agent 指令通过 go:embed 编译进二进制，按目录名作为 skill name，SKILL.md 为主文件，其余文件作为 supporting file 保留相对路径。
- 对敏感出站请求（Hook）强制 HTTPS，并通过 DevOrigins 白名单 + 独立 CA 池的方式仅在开发时放宽 TLS 校验，禁止重定向。
- 事务边界由 TxStarter.Begin 显式开启，所有写操作集中在 Service 方法内，handler 只负责参数解析与响应序列化。
