本模块以一组 Service 结构体作为领域入口（TaskService、AutopilotService、IssueService、PluginService），每个 Service 通过构造函数注入依赖（*db.Queries、TxStarter、events.Bus、entitlement.Provider、featureflag.Service 等），从而把数据库事务、事件总线、配额与特性开关从 HTTP 层解耦出来。
- 任务执行：task.go 是最大文件，集中处理 claim/start/complete/failure/reclaim/batch 等状态机；配合 empty_claim_cache.go、reclaim_check_cache.go、channel_media_reconciler.go 做并发与资源清理；runtime_teardown.go、runtime_unusable_notice.go 负责运行时健康门控。
- Autopilot：autopilot.go 提供 Dispatch/AdmitWebhook/Manual 多个入口，统一走 shouldSkipDispatch 准入检查与 RecordAutopilotRuleVersion 审计快照；quota、notification_recipient、squad 等文件按职责拆分。
- Issue：issue.go 定义 IssueCreateParams/Opts/Result，把重复检测、编号、附件链接、agent 任务入队、广播封装为单一 Create 管线。
- 插件体系：plugin.go 及 plugin_*.go 实现插件的发布、安装、配置 schema、MCP 传输、事件桥接、存储抽象、Token 签发与 Hook 安全（HTTPS + DevOrigins 白名单 + CA 信任）。
- 内置能力：builtin_skills.go 用 go:embed 将 builtin_skills/ 目录编译进二进制，按 agentSystemKey 过滤作用域；builtin_agents.go 嵌入 Mika 的系统提示并通过占位符替换组装最终指令。
- 调度：cron.go 基于 robfig/cron/v3 提供 NextOccurrenceAfterUTC / NextOccurrencesUTC 等纯函数，供 scheduler 包计算 plan_time。
依赖方向单向向下：本模块依赖 internal/*、pkg/db/generated、pkg/plugincontract、pkg/skillbundle 等底层设施，不反向被它们引用；HTTP handler 仅消费这些 Service 暴露的方法。
