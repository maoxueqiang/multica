- 所有需要鉴权的 handler 方法首行调用 `requireUserID(w, r)` 提取并校验当前用户 ID，失败时直接返回 401/403 而不继续执行业务逻辑。
- 对外响应统一通过 `writeJSON` / `writeError` / `writeErrorCode` 封装，错误路径集中返回带人类可读消息的 JSON 对象，而非裸 fmt.Errorf。
- 时间戳字段在 DB 模型与 JSON 响应之间通过 `timestampToString` / `timestampToPtr` 转换，保持 `*string` 可空语义与 ISO8601 字符串的双向映射。
- 对第三方服务调用（Google OAuth、EmailService、seatcapacity）采用 fire-and-forget goroutine 或忽略非关键错误，确保主流程不被下游故障阻塞。
- 涉及多表写入的操作（邀请接受/拒绝、撤销）一律通过 `TxStarter.Begin` 开启事务并使用 `qtx := Queries.WithTx(tx)` 提交，失败时 defer Rollback。
- 敏感标识（如 PAT 原始值）仅以哈希形式入库，展示层只输出前缀；续期与撤销通过查询哈希匹配行并做权限二次校验（PAT 所属用户与 X-User-ID 比对）。
