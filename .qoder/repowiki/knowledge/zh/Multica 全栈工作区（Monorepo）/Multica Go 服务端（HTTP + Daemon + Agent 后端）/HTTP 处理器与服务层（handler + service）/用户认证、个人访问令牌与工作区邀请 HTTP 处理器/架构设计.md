本模块由三个按业务域划分的 handler 文件组成，均挂载在 `handler.Handler` 结构体上并通过 go-chi/v5 路由：
- `auth.go`：处理邮箱验证码登录（SendCode/VerifyCode）、Google OAuth 登录（GoogleLogin）、当前用户信息读写（GetMe/UpdateMe）、CLI Token 签发（IssueCliToken）与登出（Logout）。核心流程通过 `findOrCreateUser` 统一完成“查或建”用户，并调用 `checkSignupAllowed` 执行白名单/域名白名单/全局开关三级注册限制；JWT 使用 HS256 签名并由 `internal/auth` 提供密钥与 TTL。
- `personal_access_token.go`：提供 PAT 的创建、列出、续期（RenewCurrentPersonalAccessToken）与撤销（RevokePersonalAccessToken）。续期采用 CAS 语义——以 `ExtendPersonalAccessTokenExpiry` 的阈值作为乐观锁条件，避免并发重复续期；撤销后主动调用 `PATCache.Invalidate` 立即失效缓存。
- `invitation.go`：实现工作区邀请全生命周期（Create/List/Revoke/GetMy/ListMy/Accept/Decline），通过 `TxStarter` 开启事务保证“标记邀请状态 + 创建成员 + 标记 onboarded”原子性，并与 `seatcapacity` 子模块协作完成席位预留/消费/释放的补偿语义；同时通过 `h.publish` 广播实时事件。
依赖方向单向向下：HTTP 请求 → handler 方法 → `Queries`（生成型 SQL 客户端）→ 数据库；外部副作用通过 `EmailService`、`Analytics`/`Metrics`、`seatcapacity` 与 `protocol` 事件总线解耦。测试文件 `user_language_test.go`、`user_timezone_test.go` 覆盖 UpdateMe 中对语言白名单与时区 IANA 校验的边界行为。
