- Handler 通过结构体字段注入依赖（Queries、Hub、Bus、service.*Service 等）并在 `New` 中集中装配，测试时可替换为 stub 或计数包装器。
- 可选外部集成（Lark、Slack、DingTalk、WeCom、Composio、PRRefresh、VCSSecretBox 等）以 nil-safe 字段形式注入，未配置时对应 handler 直接返回 503，避免启动失败。
- 错误响应统一通过 `writeJSON`/`writeError`/`writeErrorCode` 输出带 `error`/`code` 字段的 JSON，并显式设置 `Content-Type: application/json` 与 `Content-Length`。
- UUID 解析区分“已校验来源”的 `parseUUID`（panic 变体）与用户输入的 `parseUUIDOrBadRequest`（返回 400），禁止将原始 URL/body 字符串直接写入 DB。
- 每个 Agent provider 在 `server/pkg/agent` 中以独立文件实现 `Backend` 接口，并通过文件名/注册表与 `builtin_runtimes.go` 关联，新增 provider 只需新增文件并注册。
- Daemon 中的超时、TTL、心跳间隔等运行时参数以包级 `var` 暴露（如 `pendingWorkHintMinInterval`、`taskPrepareLeaseTimeout`），便于测试覆盖调小。
