- 路由按功能划分为 `(auth)`、`(landing)`、`[workspaceSlug]/(dashboard)` 三组，各自独立 layout 与 loading 文件，禁止跨组混用。
- 工作区仪表板下的每个子功能（agents、runtimes、issues、billing 等）均以 `[workspaceSlug]/(dashboard)/xxx/page.tsx` 形式挂载，并由 `@multica/views` 提供实际 UI。
- Web 平台特定能力统一收敛到 `platform/` 目录，以 Provider 或 hook 形式暴露给上层路由，避免在页面中直接调用浏览器 API。
- 跨路由共享的纯函数工具集中在 `lib/`，并按职责拆分为 locale-routing、docs-href、workspace-slug-from-pathname、use-cases-i18n 等独立模块。
- 测试文件与源码同目录放置，命名约定为 `<file>.test.ts(x)`，由 `vitest.config.ts` 统一收集。
