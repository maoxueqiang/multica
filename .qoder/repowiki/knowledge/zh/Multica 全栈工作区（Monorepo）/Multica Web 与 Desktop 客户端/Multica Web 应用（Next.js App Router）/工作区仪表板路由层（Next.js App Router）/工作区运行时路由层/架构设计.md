该模块是 Next.js App Router 的路由薄壳，仅负责解析动态段参数并委托给共享视图层：
- `page.tsx`：列表页，读取 `NEXT_PUBLIC_ENABLE_CLOUD_RUNTIME` 环境变量并通过 props 控制云运行时开关。
- `[id]/page.tsx`：单台机器详情页，使用 React 19 的 `use(params)` 异步解构 `id`，传入 `RuntimeDetailPage`。
- `[id]/runtime/[runtimeId]/page.tsx`：机器内特定 runtime 的设置页，同时解构 `id`（machineId）与 `runtimeId` 传给 `RuntimeSettingsPage`。
依赖方向严格单向：本目录 → `@multica/views/runtimes`，不包含任何业务逻辑或 UI 实现，仅做路由参数装配与功能开关透传。
