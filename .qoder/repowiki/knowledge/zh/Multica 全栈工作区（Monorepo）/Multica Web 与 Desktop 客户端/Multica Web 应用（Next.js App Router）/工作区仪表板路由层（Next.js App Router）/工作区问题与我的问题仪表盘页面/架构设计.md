本模块由三个 Next.js 客户端页面组成，作为 `apps/web` 下 `[workspaceSlug]/(dashboard)` 路由组的具体实现：
- `issues/page.tsx`：通过 `@multica/views/issues/components` 的 `IssuesPage` 渲染工作区问题列表，并在 `Suspense` 中调用 `useIssueViewUrlSync({ scope_type: 'workspace' })` 将搜索参数与 URL 同步。
- `my-issues/page.tsx`：通过 `@multica/views/my-issues` 的 `MyIssuesPage` 渲染“我的问题”列表，URL 同步时传入 `scope_type: 'my'`。
- `issues/[id]/page.tsx`：使用 React Server Components 的 `params` Promise + `use()` 解构动态 `id`，并通过 `ErrorBoundary resetKeys={[id]}` 包裹 `IssueDetailRoute` 以支持按 id 重置错误状态。
依赖方向严格遵循 views -> core/ui：页面仅做路由装配（Suspense、ErrorBoundary、URL 同步），业务 UI 全部委托给 `@multica/views`，通用错误处理来自 `@multica/ui`，平台级 URL 同步逻辑位于同级 `platform/use-issue-view-url-sync`。
