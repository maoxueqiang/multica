本模块由 Next.js App Router 的三段式页面文件组成，位于 `[workspaceSlug]/(dashboard)` 布局组下：`chat/page.tsx`、`inbox/page.tsx` 为无状态路由壳，直接 re-export `@multica/views/chat` 与 `@multica/views/inbox` 的默认导出；`members/[id]/page.tsx` 使用 `'use client'` 并通过 React 19 的 `use(params)` 解析动态路由参数 `id`，再将其作为 `userId` 传递给 `@multica/views/members` 的 `MemberDetailPage`。依赖方向严格遵循 views -> core + ui 约定，本模块仅做路由装配与参数透传，不包含业务逻辑。
