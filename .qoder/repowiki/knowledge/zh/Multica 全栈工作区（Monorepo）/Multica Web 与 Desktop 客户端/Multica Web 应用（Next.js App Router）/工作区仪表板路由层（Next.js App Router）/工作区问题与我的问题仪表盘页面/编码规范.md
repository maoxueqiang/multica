- 每个页面文件顶部声明 `'use client'`，并将所有数据获取与副作用下沉到 `@multica/views` 组件中，页面本身保持薄装配。
- 通过本地 `IssueViewUrlSync` 子组件在 `Suspense` 边界内调用 `useIssueViewUrlSync`，以兼容 `useSearchParams` 对 Suspense 的要求。
- 列表页使用全局 `ErrorBoundary`，详情页使用带 `resetKeys={[id]}` 的 `ErrorBoundary` 实现按资源标识重置错误状态。
- 通过 `useIssueViewUrlSync` 的 `scope_type` 参数区分工作区维度（`workspace`）与个人维度（`my`）的问题视图。
