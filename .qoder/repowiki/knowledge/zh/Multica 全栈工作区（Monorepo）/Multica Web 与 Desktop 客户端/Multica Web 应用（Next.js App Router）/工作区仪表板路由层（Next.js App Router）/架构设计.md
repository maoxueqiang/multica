本模块是 Next.js App Router 的路由装配层：每个子目录对应一个工作区功能域（agents、runtimes、issues、billing/usage/settings、chat/inbox/members、projects/skills/squads/autopilots），通过 page.tsx 把 URL 参数透传给 @multica/views 中的业务页面组件，实现 views -> core + ui 的单向依赖。所有子路由共享同一份 layout.tsx，该布局在 @multica/views/layout 的 DashboardLayout 中注入搜索命令、浮动聊天、Web 通知桥和工作区文档标题，从而统一侧边栏导航与全局 UI 壳；loading.tsx 提供路由级加载占位。各子路由之间不直接通信，仅通过 @multica/core 的状态与 @multica/views 的共享组件进行协作。
