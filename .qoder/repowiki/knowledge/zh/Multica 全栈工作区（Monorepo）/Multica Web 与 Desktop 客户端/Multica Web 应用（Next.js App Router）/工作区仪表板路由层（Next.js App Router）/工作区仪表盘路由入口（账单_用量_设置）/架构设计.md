本模块由 Next.js App Router 的分组路由 `(dashboard)` 下的三个目录组成：`billing/page.tsx`、`usage/page.tsx`、`settings/page.tsx`。每个文件仅作为薄路由层，不承载业务逻辑，全部通过 `import ... from "@multica/views/*"` 引入并渲染共享视图组件（`BillingTestPage`、`DashboardPage`、`SettingsPage`）。尽管路由位于 `[workspaceSlug]` 下以复用认证壳与布局，但 `billing` 页面明确说明其数据属于账户级而非工作区级，slug 仅用于路由归属。依赖方向单向指向 `@multica/views`，本模块自身不依赖任何本地子模块。
