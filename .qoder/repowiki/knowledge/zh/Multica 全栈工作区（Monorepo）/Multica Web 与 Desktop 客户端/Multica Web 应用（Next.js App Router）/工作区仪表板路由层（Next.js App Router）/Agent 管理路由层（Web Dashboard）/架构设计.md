本模块是 Next.js App Router 的叶子路由层，位于 `[workspaceSlug]/(dashboard)/agents/` 路径组内，仅负责 URL → 视图组件的映射，不包含任何业务逻辑。
- 路由结构：`page.tsx` 渲染 Agent 列表；`new/page.tsx` 提供创建方式选择；`new/ai/page.tsx` 与 `new/ai/[sessionId]/page.tsx` 对应 AI 引导式创建流程；`new/manual/page.tsx` 对应手工创建；`[id]/page.tsx` 展示单个 Agent 详情。
- 所有路由页均通过 `import { ... } from "@multica/views/agents"` 引入共享页面组件，遵循 views -> core + ui 的依赖方向，本模块不直接依赖 core/ui。
- 动态参数使用 React Server Components 的 `params: Promise<{...}>` 配合 `react.use()` 解构后以 props 形式传给客户端组件（如 `agentId`、`sessionId`），体现 RSC → Client Component 的参数透传模式。
- 列表页在注释中明确 Web 端无本地 daemon 上下文，因此运行时过滤始终将本地模式归为 Remote，这是 Web 与 Desktop 的差异点，由桌面端另行注入。
