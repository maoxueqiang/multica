模块按职责拆分为两个目录：`apps/web/lib/` 存放面向请求/页面的纯函数工具，`apps/web/config/runtime-urls.ts` 集中管理前端构建期与运行期的 URL 解析与代理重写规则。

- 国际化与语言路由：`locale-routing.ts` 从 `@multica/core/i18n` 导出 `SUPPORTED_LOCALES` 和 `matchLocale`，定义 `MULTICA_LOCALE_HEADER`；`request-locale.ts` 通过 Next.js `cache` + `headers()`/`cookies()` 实现带缓存的请求级 locale 解析（优先自定义 header，再回退 cookie + Accept-Language）；`use-cases-i18n.ts` 将 `getRequestLocale` 重导出为 `getUseCaseLocale`，并以 `Record<SupportedLocale, UseCaseText>` 形式内联多语言文案；`html-lang.ts` 维护内部 locale 到 BCP-47 HTML lang 的映射；`docs-href.ts` 根据 locale 生成 `/docs/*` 路径。
- 用例内容源：`use-cases-source.ts` 基于 `fumadocs-core` 的 `loader` 与 `defineI18n`，以 dot-suffixed MDX（`.en/.zh/.ko/.ja.mdx`）驱动 `/usecases` 路由，并通过 `use-case-locale-fallback.ts` 在非默认语言下合并英文页作为 fallback；`workspace-slug-from-pathname.ts` 从 pathname 解码首段作为 workspace 标识，供 `app/[workspaceSlug]/layout.tsx` 比对。
- 运行时 URL 配置：`runtime-urls.ts` 提供 `resolveRemoteApiUrl`、`resolveDevRemoteApiUrl`、`resolveBrowserApiBaseUrl`、`resolveDocsUrl`、`resolveBrowserWsUrl` 等解析器，并在 `runtimeRewriteDestination` 中把 `/api`、`/v1`、`/uploads`、`/ws`、`/health`、`/auth/**` 等路径转发至后端 origin；内置 `stripApiPathSuffix` 防止 `NEXT_PUBLIC_API_URL` 末尾带 `/api` 导致双重前缀。
- 依赖方向单向向外：本模块仅依赖 `@multica/core/i18n`、`fumadocs-core`、Next.js 内置 API（`next/headers`、`react/cache`），不反向被 core/ui 依赖，属于 web 层共享工具。
