- 所有 locale 相关能力都围绕 `@multica/core/i18n` 的 `SupportedLocale` 类型展开，新增语言需在多处映射（`HTML_LANG`、`docsHrefForLocale`、`getUseCaseLangForLocale`、`useCaseText`）同步补齐。
- URL 解析统一采用「先 clean/validate，再返回 undefined 表示未配置」的模式，由调用方决定走同域相对路径还是显式 origin。
- 对来自浏览器环境的字符串（pathname、cookie、header）在比较前先做 trim/lowercase/去尾斜杠规范化，避免大小写与尾部 `/` 导致的匹配失败。
- 每个工具文件均配有同名 `.test.ts` 单元测试，覆盖边界情况（如空 pathname、非法 `%` 编码、非 http(s) URL）。
