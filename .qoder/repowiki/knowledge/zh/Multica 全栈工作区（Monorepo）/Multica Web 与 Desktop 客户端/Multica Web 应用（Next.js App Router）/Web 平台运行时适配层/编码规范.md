- 每个平台能力以独立的 `*Provider` React 组件形式暴露，内部构造一个适配器对象（如 `NavigationAdapter`、`ScrollRestorationAdapter`）注入到共享的 `@multica/views` Provider 中。
- 对浏览器全局对象的访问统一通过 `typeof window === 'undefined'` 守卫或可选链（如 `navigator`、`window.navigation`）保证在服务端渲染时不报错。
- 模块级单例 Map（如 `savedOffsets`、`savedViewState`、`suppressedUntil`）作为 per-tab 状态存储，键由 `pathname` 与容器标识拼接而成，生命周期随浏览器标签页。
- URL 与视图状态的同步采用「mount 时从 URL 采纳、之后 store → URL via replaceState」的双向模式，避免触发完整导航与滚动重置。
- 测试文件与源文件同名并列放置（`.test.ts` / `.test.tsx`），便于按功能一一对应验证。
