本模块是 web/desktop 共享视图层（@multica/views）在 Web 端的实现层，按功能拆分为独立文件，每个文件暴露一个 Provider/Hook 作为平台适配入口：
- 导航适配：`navigation.tsx` 通过 `NavigationProvider` 将 Next.js `useRouter`/`usePathname`/`useSearchParams` 包装成 `NavigationAdapter`，并监听 `multica:navigate` 自定义事件以支持跨内容编辑器的内部链接跳转；`in-app-history.ts` 基于 Navigation API 的 `entries()` 判断是否可安全回退到应用内页面。
- 滚动恢复：`scroll-restoration.tsx` 用 capture 阶段的全局 scroll 监听记录带 `data-tab-scroll-root` 容器的偏移量，并通过 `ScrollRestorationProvider` 暴露给 views 读取，键由 `pathname::containerKey` 组成，配合 `suppressedUntil` 防抖避免恢复时覆盖用户滚动。
- 文档标题：`document-title.ts` 定义纯函数常量（`SITE_TITLE`、`TITLE_SUFFIX`、`MAX_PAGE_TITLE_LENGTH`），被服务端 layout 与客户端 `workspace-document-title.tsx` 共用，后者通过 `parseTabSubject` + `useTabPresentation` 解析 URL 并同步 `document.title`。
- 其他运行时：`client-os.ts` 仅依赖 `navigator.platform/userAgent` 做粗粒度 OS 探测；`user-locale-sync.ts` 与 `use-issue-view-url-sync.ts` 分别处理账户语言切换与问题视图 ID 的双向 URL 同步。
依赖方向单向向下：本模块依赖 `@multica/views/*` 提供的抽象 Provider/Adapter 类型与 `@multica/core/*` 的路径/状态工具，不反向被 core/ui 依赖。
