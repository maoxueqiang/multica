- 每个路由页面通过 `page.tsx` 暴露默认组件并集中声明 `Metadata`（title/description/openGraph/canonical），SEO 信息不分散到组件内部。
- 服务端页面只负责数据获取与 props 传递，UI 细节下沉到 `features/landing/components` 中的独立组件文件，保持路由薄、组件厚。
- 需要状态或浏览器 API 的组件统一以 `'use client'` 指令标注，并与相邻的服务端页面文件分离存放。
- 国际化通过 `i18n/context.tsx` 的 `LocaleProvider` + `useLocale()` 消费，新增语言只需在 `dictionaryFactories` 注册工厂并在 `types.ts` 扩展 Locale 枚举。
- 外部数据请求（如 GitHub Release）在服务端完成并配合 `next: { revalidate }` 做 ISR 缓存，失败时返回空结构降级而非抛错。
- 客户端重定向统一使用 `router.replace` 避免污染浏览器历史，且仅在非官方营销主机上生效，保证营销站 `/` 始终公开可访问。
