模块以 `main.tsx` 为渲染进程入口，通过 `AppCrashBoundary` 包裹 `App.tsx`；`App.tsx` 在启动阶段解析运行时配置、系统语言、深度链接（`multica://auth/callback`、`multica://invite`），并挂载 `CoreProvider`、`DesktopAuthSessionBridge`、`DiagnosticRouteReporter`、`DesktopClientUsageReporter` 等平台适配层，再根据 `window.desktopAPI.windowContext.kind` 分流到主窗口 `AppContent`（进入 `DesktopShell`）或独立 `IssueWindowContent`。

- 路由：`routes.tsx` 用 `react-router-dom` 的 `createMemoryRouter` 定义单例路由树，所有业务页面来自 `@multica/views/*`，桌面特有路由（runtimes、agents、settings daemon/updates tab）在此扩展；每个路由通过 `handle.title` 驱动 `TitleSync` 同步 `document.title`。
- 导航：`platform/navigation.tsx` 实现 `NavigationAdapter`，拦截跨工作区跳转、预工作区过渡路径（`/workspaces/new`、`/onboarding`、`/invitations`、`/invite/*`）并打开 `WindowOverlay`，将 push/replace/openInNewTab 映射到 `tab-store` 的会话操作，遵守 MUL-4741 单路由器架构——适配器不直接调用 router，仅修改 store，由 Coordinator 投影到内存路由。
- 状态：`stores/tab-store.ts` 基于 Zustand + `persist` 维护按工作区分组的 `WorkspaceTabGroup`，每个 Tab 是 `TabSession`（url、resourceKey、pinned、虚拟 history stack、memento 滚动/视图状态），提供 `switchWorkspace`、`openTab`、`navigateActiveSession`、`goBack/Forward`、`commitScrollMemento`、`commitViewState` 等方法；`window-overlay-store.ts` 管理覆盖层。
- 布局：`components/desktop-layout.tsx` 的 `DesktopShell` 组合 `SidebarProvider`、`WindowToolbar`、`AppSidebar`、`TabBar`、`TabContent`、`WindowOverlay`，并通过 `useInternalLinkHandler` 监听 `multica:navigate` 事件统一走 `routeContentLinkPath`。
- 平台桥：`platform/` 下集中 Electron/主进程能力——`daemon-ipc-bridge`、`auth-session-bridge`、`daemon-login-sync`、`daemon-reauth`、`session-teardown`、`client-usage-reporter`、`diagnostic-route-reporter`、`i18n-adapter`、`issue-window-navigation`、`tab-coordinator`、`use-local-runtimes-pending`，全部通过 `window.desktopAPI` / `window.daemonAPI` 暴露的注入 API 通信。
- 页面：`pages/` 包含登录、认证恢复及详情型页面（issue/project/agent/skill/member/runtime/autopilot/ai-builder-session/attachment-preview），均复用 `@multica/views` 中的共享页面组件。
- 钩子：`hooks/` 提供 `use-document-title`、`use-tab-history`、`use-open-settings-shortcut`、`use-tab-selection-shortcut` 等桌面快捷键与历史行为。
依赖方向严格遵循 views -> core + ui，本模块只消费 `@multica/core/*`、`@multica/ui/*`、`@multica/views/*`，不反向依赖它们。
