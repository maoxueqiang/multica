该模块是 desktop 应用内无运行时依赖的纯类型与工具层，按职责拆分为若干独立文件：
- 进程间通信契约：`main-renderer-messages.ts` 集中声明 main↔renderer 的消息 channel（如 `auth:token`、`invite:open`）并提供 `MainRendererMessageQueue`，用于在 React 监听器就绪前缓存并回放消息；`navigation-gestures.ts`、`auth-session.ts` 分别定义手势与认证会话通道。
- 外部子进程协议：`daemon-types.ts` 描述本地 daemon 状态机（`DaemonState`）、`DaemonStatus`、`DaemonPrefs` 及颜色/文案映射；`updater-types.ts` 描述自动更新偏好与手动检查结果。
- 启动参数与窗口上下文：`issue-window.ts` 通过 `--multica-issue-window=` 命令行参数在 main 与 renderer 之间传递受限的 issue 详情窗口请求，使用白名单正则严格校验 workspace slug 与 issue id。
- 运行时配置：`runtime-config.ts` 提供 `RuntimeConfig` schemaVersion=1 的 JSON 解析、dev/prod URL 推导（`deriveWsUrl`、`deriveAppUrl`、`deriveDevAppUrl`）及 http/ws URL 规范化。
- 诊断数据：`renderer-route-context.ts` 将渲染器路由上下文脱敏为仅含模板的路径后上报；`freeze-breadcrumb.ts` 定义冻结/崩溃断点记录结构，供 main/preload/renderer 三方共享。
所有文件均不引入任何框架或运行时库，仅导出类型、常量与纯函数，被 apps/desktop 内的 main、preload、renderer 以及 shared 其他模块共同消费，形成单向依赖的契约层。
