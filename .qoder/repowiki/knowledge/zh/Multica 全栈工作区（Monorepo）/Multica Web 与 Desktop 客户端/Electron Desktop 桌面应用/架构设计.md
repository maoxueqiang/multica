本模块以 Electron 三进程模型组织：`src/main` 负责窗口生命周期、自动更新、CLI/daemon 管理与跨渲染器会话协调；`src/renderer` 是 React 渲染应用，提供多工作区标签页、路由导航与桌面专属页面（登录、设置、问题窗口）；`src/preload` 暴露安全 API 给渲染进程；`src/shared` 集中定义主进程、渲染进程、预加载脚本与本地 daemon 之间的 TypeScript 类型、消息通道常量及输入校验/序列化函数，构成跨进程契约。构建侧由 `scripts/` 下的 Node 脚本驱动 electron-vite 打包、多平台矩阵构建与工作树隔离开发，`resources/bin/multica` 作为被嵌入的本地 CLI 二进制。依赖方向严格为 renderer → shared + preload → main，并通过 `shared/main-renderer-messages.ts` 等文件统一 IPC 协议。
