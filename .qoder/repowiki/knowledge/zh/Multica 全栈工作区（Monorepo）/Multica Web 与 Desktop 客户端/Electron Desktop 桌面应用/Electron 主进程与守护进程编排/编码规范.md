- 每个功能域以独立文件组织并通过 `setupXxx(getMainWindow)` 形式在 `index.ts` 中集中装配，保持主进程启动流程线性可读。
- 跨渲染器通信统一通过 `../shared/*` 中声明的通道字符串常量与 TypeScript 类型进行编解码，避免魔法字符串散落。
- 对共享资源（profile JSON 写入、daemon 生命周期操作）使用链式 Promise 或 `DaemonOperationGate` 串行化，防止竞态导致状态损坏。
- 对外部命令执行一律带超时与输出校验（如 `execFile(..., { timeout })` 后解析 JSON），失败路径返回结构化错误而非抛出未捕获异常。
- 平台差异通过 `process.platform` 分支显式处理（macOS dock badge、Linux AppImage icon、Windows arm64 更新通道），不在运行时猜测能力。
- 测试文件与源码同名并列放置（`.test.ts`），便于通过文件名快速定位被测单元。
