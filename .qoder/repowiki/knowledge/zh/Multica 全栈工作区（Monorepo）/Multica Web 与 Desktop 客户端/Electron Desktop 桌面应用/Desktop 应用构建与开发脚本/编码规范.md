- 所有外部命令（git、go、electron-vite、electron-builder、PlistBuddy、codesign）均通过 `child_process.execFileSync`/`spawnSync` 以 argv 数组形式调用，禁止拼接 shell 字符串以避免 Windows cmd.exe 引号转义问题。
- 平台/架构映射集中声明为常量表（`PLATFORM_CONFIG`、`ARCH_FLAGS`、`PLATFORM_TO_GOOS`），新增目标只需扩展这些表而非散落 if/else。
- 可复用的纯函数（`normalizeGitVersion`、`stripLeadingSeparator`、`parsePackageArgs`、`resolveBuildMatrix`、`builderArgsForTarget`、`envWithLocalBins`、`cksum`、`rendererPortForPath`）独立导出并由 `*.test.mjs` 直接 import 断言，使构建逻辑具备单元测试覆盖。
- 通过 `process.argv[1]` 与 `import.meta.url` 比较判断脚本是否被直接执行，从而在同一文件中共存 CLI 入口与可被测试导入的模块。
- PATH 注入统一通过 `envWithLocalBins` 将 `apps/desktop/node_modules/.bin` 与仓库根 `node_modules/.bin` 前置到子进程环境，保证 hoisted 与 isolated linker 两种 pnpm 布局均可找到本地 bin。
- 对 git 标签匹配模式（`v[0-9]*`）始终作为单独 argv 元素传递，不在任何地方拼入 shell 字符串，防止 Windows 上单引号泄漏导致版本回退到 `0.0.0-g<hash>`。
