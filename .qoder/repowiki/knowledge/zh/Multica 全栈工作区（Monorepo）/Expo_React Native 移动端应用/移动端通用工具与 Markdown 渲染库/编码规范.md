- 每个纯函数工具都配有同名 `.test.ts` 单元测试文件，位于同一目录下便于定位。
- WebSocket 订阅统一通过 `useWSSubscriptions(setup, deps)` 钩子注册，setup 回调返回 unsubs 数组并在 cleanup 中逐一调用，避免重复的生命周期样板。
- Markdown 渲染采用预处理 → 分段 → 按段渲染三段式管线，prose/code/image 各自独立组件，新增片段类型需同时更新 `split-markdown` 与 `markdown.tsx` 的 switch。
- 主题色通过 `THEME.light/dark` 对象集中声明并与 `global.css` 的 CSS 变量保持键名一一对应，React Navigation 的 `NAV_THEME` 由该对象派生。
- 对外部不可信数据（如 API 响应）一律通过 `parseWithFallback` 用 Zod schema 安全解析，失败时记录警告并返回 fallback，禁止向 UI 抛出异常。
- Mention 输入状态由 `useMentionInput` 统一管理，通过 ref 同步 text/selection 以规避 React 批处理导致的同 tick 事件竞态，并提供 snapshot/restore/reset 支持乐观提交回滚。
