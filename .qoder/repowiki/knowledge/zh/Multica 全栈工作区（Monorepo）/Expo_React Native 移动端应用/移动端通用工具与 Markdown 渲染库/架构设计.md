模块以扁平文件组织，按职责分为四类：
- 纯工具函数（`utils.ts`、`format-*`、`time-ago.ts`、`inline-color.ts`、`request-id.ts`、`quick-emojis.ts`）：无副作用，仅依赖 `@multica/core/types` 类型。
- 业务格式化器（`attachment-dedup.ts`、`chat-session-title.ts`、`inbox-display.ts`、`group-issues-by-category.ts`、`search-rows.ts`、`timeline-coalesce.ts`、`timeline-thread.ts`、`issue-status.ts`、`project-status.ts`、`run-failure-badge.ts`、`dispatch-reason.ts`、`failure-reason-label.ts`、`filter-issues.ts`、`mention-serialize.ts`、`strip-markdown.ts`、`parse-response.ts`）：将后端数据转换为 UI 展示值，其中 `parse-response.ts` 在移动端镜像 core 的 Zod schema 做边界防御，避免引入核心包。
- React Hooks（`use-ws-subscriptions.ts`、`use-agent-presence.ts`、`use-workspace-presence-prefetch.ts`、`use-issue-statuses.ts`、`use-mention-input.ts`、`use-color-scheme.ts`、`use-native-search-bar.ts`、`use-scroll-to-top-on-change.ts`、`use-clear-filters-on-workspace-change.ts`、`workspace-agent-availability.ts`）：封装跨组件共享状态；`use-ws-subscriptions.ts` 作为 Layer-3 实时订阅的通用骨架，所有 `use-*-realtime` hook 通过它复用 ws 生命周期。
- Markdown 子系统（`lib/markdown/`）：`markdown.tsx` 是入口，通过 `preprocessMobileMarkdown` → `splitMarkdown` 将内容切分为 prose/code/image 三段，分别交由 `EnrichedMarkdownText`、自研 `CodeBlock`（Shiki 高亮）、`MarkdownImage`（expo-image + lightbox）渲染；`index.ts` 暴露 `Markdown`、`LightboxProvider`、`prewarmHighlighter`；`shiki.ts`、`tokens.ts`、`markdown-style.ts` 负责语法高亮与样式。
依赖方向单向：本模块只从 `@multica/core/types` 取类型、从 `@/data/*` 读 workspace/store/ws-client 状态，不反向被 core 或 web 依赖；主题通过 `theme.ts` 同步 `global.css` CSS 变量到 TypeScript 对象，供 React Navigation 与内联样式共用。
