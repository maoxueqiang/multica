模块以 Expo Router 的文件路由为核心组织：根 `_layout.tsx` 装配 `GestureHandlerRootView`、`SafeAreaProvider`、`KeyboardProvider`、`QueryClientProvider`、`ThemeProvider`、`LightboxProvider` 等全局 Provider，并通过 `AuthInitializer` 在进程启动时注册 `api.setOptions.onUnauthorized` 处理 401 并跳转 `/login`；`index.tsx` 作为入口根据 `useAuthStore.isLoading`、`user`、`currentWorkspaceSlug` 三态重定向到 `/login`、`/select-workspace` 或 `/${slug}/inbox`。

路由按功能分为三个组：`(auth)`（登录/验证）、`(app)`（需登录）、以及动态 `[workspace]` 段（当前工作区）。`[workspace]/_layout.tsx` 是核心编排层：读取 URL slug 校验成员资格、写入 Zustand 工作区 store、重置跨路由草稿 store、通过 `RealtimeProvider` 挂载 inbox/issues/my-issues/chat/projects/pins/presence 等全部实时订阅，并以集中式 `<Stack.Screen>` 列表声明所有页面、模态和 formSheet 路由（issue/project 详情、编辑、picker 选择器、new-issue/new-project、search、switch-workspace、more/* 子菜单）。

`(tabs)/_layout.tsx` 定义底部四标签（Inbox、My Issues、Chat、More），其中 More 通过 `listeners.tabPress` + `preventDefault` 打开下拉菜单而非导航；badge 使用 `useInboxUnreadCount`/`useChatUnreadMessageCount` 驱动。依赖方向单向向外：本模块仅消费 `@/data/*`（store、queries、realtime hooks）、`@/lib/*`（theme、unread counts、markdown highlighter）与 `@/components/ui/*`，不反向引用业务组件实现。
