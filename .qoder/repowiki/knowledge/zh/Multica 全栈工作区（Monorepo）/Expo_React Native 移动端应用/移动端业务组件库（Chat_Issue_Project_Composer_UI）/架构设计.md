模块按业务域划分子目录：`chat/` 实现基于 FlashList v2 的消息流、会话状态条与长压交互；`issue/` 覆盖问题行、时间线、评论卡片以及 `pickers/` 下的成员/状态/优先级等选择器；`project/` 提供项目行与属性区块；`composer/` 暴露跨场景复用的 `MessageComposer`；`editor/` 封装 Markdown 工具栏与文件附件 Hook；`ui/` 是原子级基础组件（Button、Input、Avatar、Tabs、Card 等），通过 `class-variance-authority` + NativeWind 类名组合输出样式；`brand/`、`nav/`、`workspace/` 为少量品牌与导航辅助组件。依赖方向严格自下而上：业务组件仅从 `@/components/ui/*` 引用原子组件，从 `@multica/core/types` 引入类型与纯函数，数据获取统一经由 `@/data/queries/*` 的 React Query options，状态通过 zustand store（如 `useChatSelectStore`、`useMentionDraftStore`）共享，避免直接耦合页面路由。
