- 业务组件通过 props 暴露回调（如 `onSubmit`、`onPickPrompt`、`onChange`），自身不持有提交或路由逻辑，保持纯展示与交互编排。
- UI 组件统一使用 `class-variance-authority` 定义 variant/size 变体，并通过 `cn()` 组合 NativeWind 类名，按钮、图标等遵循同一模式。
- 列表渲染优先选用 FlashList（如 ChatMessageList），并启用 `maintainVisibleContentPosition` 与 `startRenderingFromBottom` 保证底部锚定与首帧定位。
- 选择器 body 组件（assignee/status/priority/project 等）采用 discriminated union 的 Row 类型 + `kind` 字段区分数据源，统一在 `renderItem` 中分支渲染。
- 对外部枚举/类型变更采用降级策略（未知 role 降级为 assistant、未知 assignee_type 走 ActorAvatar 默认头像），避免崩溃而非白名单拦截。
- 富文本内容统一经 `@/lib/markdown` 的 Markdown 组件渲染，附件通过 `CommentAttachmentList` 与正文去重后作为独立卡片展示。
