模块以 `app/` 下的 Expo Router 分组（`(auth)`、`(app)/[workspace]`）作为入口，通过 `_layout.tsx` 挂载认证守卫、实时订阅与工作区上下文；业务页面由 `components/` 中的 Chat/Issue/Project/Composer/UI 等目录组件构成；数据层集中在 `data/`，按 queries/mutations/realtime/stores 分层，并通过 `query-client.ts` 统一接入 TanStack Query，WebSocket 实时更新由 `realtime/ws-client.ts` 驱动并在路由布局中订阅；纯函数与主题常量放在 `lib/`，被组件与 data 层共同引用。依赖方向严格单向：components → lib + data → @multica/core（仅引入类型与纯函数），不反向依赖 UI 或 web/desktop 共享层。
