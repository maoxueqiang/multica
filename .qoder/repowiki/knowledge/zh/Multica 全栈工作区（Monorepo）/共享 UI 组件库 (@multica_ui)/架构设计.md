模块以 npm 包 `@multica/ui` 形式发布，通过 `package.json` 的 `exports` 字段将 `components/ui/*`、`components/common/*`、`markdown/*`、`hooks/*`、`lib/*`、`styles/*`、`types/i18next.ts` 分别暴露为独立子路径入口，使上层仅能消费已声明的 API。
- `components/ui/`：由 shadcn (`components.json` 配置 base-nova 风格) 生成的原子 UI 组件（button、dialog、table、tabs 等），全部基于 `@base-ui/react` 并配合 Tailwind CSS。
- `components/common/`：业务语义更高的组合组件（actor-avatar、emoji-picker、reaction-bar、submit-button、error-boundary、theme-provider 等），复用 `components/ui` 中的原子组件。
- `markdown/`：基于 `react-markdown` + `remark-gfm`/`rehype-katex`/`rehype-sanitize`/`shiki` 的 Markdown 渲染管线，拆分为 `Markdown`、`StreamingMarkdown`、`CodeBlock`、`linkify`、`mentions`、`issue-identifiers`、`file-cards`、`sanitize` 等职责单一的文件，统一由 `index.ts` 重导出。
- `hooks/`：纯 React Hook（use-mobile、use-scroll-fade）。
- `lib/`：无副作用工具函数（cn 合并 class、avatar 尺寸/表情、clipboard、data-table 辅助、motion 动画、code-style 高亮样式）。
- `styles/tokens.css`、`styles/base.css`：Tailwind 设计令牌与全局基础样式，被 `components.json` 指定为 Tailwind CSS 入口。
- `types/i18next.ts`：为 i18next 类型增强提供共享类型定义。
依赖方向单向向下：common → ui；markdown/hooks/lib 不反向依赖 components；本包自身不依赖 `@multica/core`，保持与 core 相互独立。
