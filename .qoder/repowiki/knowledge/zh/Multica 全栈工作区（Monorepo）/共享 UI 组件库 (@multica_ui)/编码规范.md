- 组件按原子与组合分层组织：`components/ui/` 存放无业务语义的原子组件，`components/common/` 存放组合后的业务组件，后者只能引用前者而不能反向依赖。
- 所有子目录均通过 `package.json` 的 `exports` 字段显式声明可对外导出的路径，未列出的文件视为内部实现不被外部消费。
- 类名合并统一通过 `lib/utils.ts` 导出的 `cn()` 函数完成，该函数在 tailwind-merge 中扩展了自定义字体大小类别以保持冲突分组正确。
- Markdown 渲染能力按处理阶段拆分到独立文件（linkify、mentions、issue-identifiers、file-cards、sanitize），再由 `markdown/index.ts` 统一聚合导出。
- 组件默认导出命名组件函数而非 default export，并通过 `export type ...Props` 同时导出 props 类型以便调用方推断。
- 样式变量集中定义在 `styles/tokens.css`，并在 `components.json` 中作为 Tailwind CSS 入口引入，确保 shadcn 生成的组件与设计令牌一致。
