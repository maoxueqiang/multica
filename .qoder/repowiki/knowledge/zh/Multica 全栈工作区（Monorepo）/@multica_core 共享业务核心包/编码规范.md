- 每个领域目录采用 `queries.ts` / `mutations.ts` / `store.ts`（或 `stores/`）/ `use-*.ts` 的分层组织，将数据获取、变更、状态与 React 钩子解耦。
- 对外 API 通过 `package.json` 的 `exports` 字段精确声明子路径导出，而非依赖 barrel 文件自动聚合。
- 类型定义集中在 `types/` 下按领域拆分文件，再由 `types/index.ts` 统一 re-export，供跨端共享。
- 领域模块对后端交互统一通过 `api/index.ts` 暴露的全局 `api` 代理或 `setApiInstance()` 注入的 `ApiClient`，避免直接 import HTTP 实现。
- Zustand store 与对应组件测试成对放置（如 `view-store.ts` + `view-store.test.ts`），并使用 `vi.mock` 模拟 `@tanstack/react-query`。
- WebSocket 实时更新通过 `ws-updaters.ts` 集中注册处理器，由 `realtime/provider.tsx` 分发事件，实现消息路由与状态更新的解耦。
