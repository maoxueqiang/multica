仓库采用 monorepo 结构：Go 服务端位于 server/，前端共享层按依赖方向 packages/core → packages/ui → packages/views 分层，apps/web、apps/desktop、apps/mobile、apps/docs 消费这些包；Turborepo 通过 turbo.json 定义 build/typecheck/test/lint 任务并缓存输出，pnpm-workspace.yaml 用 catalog 锁定跨包共享依赖版本。Makefile 是顶层入口，封装 dev-env.sh 脚本实现多环境（main checkout / worktree）的 up/down/status/gc，并通过 docker-compose.selfhost.yml 启动官方镜像或从源码构建 self-host 栈（backend + web + postgres）。e2e/ 使用 Playwright 对 Web/Desktop 进行端到端测试，examples/plugins/ 提供可热插拔的插件示例，.agents/skills 与 SKILL.md frontmatter 支持运行时渐进式加载智能体技能。部署由 deploy/helm/multica 提供 Helm Chart，.goreleaser.yml 负责 Go 二进制与 Docker 镜像发布。
