- 多语言文档采用 `page.<lang>.mdx` + `meta.<lang>.json` 的 dot 命名约定，由 i18n parser 自动识别，默认语言（en）省略后缀。
- 所有页面布局统一通过 `app/[lang]/layout.tsx` 包裹 `RootProvider`/`DocsLayout`，并在 sidebar footer 中注入统一的 `<DocsSettings>` 语言/主题切换控件。
- URL 语言前缀处理集中在 `middleware.ts` 与 `components/docs-settings.tsx` 中的 `switchLocalePath`，遵循“默认语言无前缀、其他语言保留前缀”的规则。
- 搜索接口对非英语语言通过 `localeMap` 注入自定义 tokenizer，中文按 CJK 字符切分、日文扩展至平假名/片假名片段，保持拉丁/数字词组完整。
- UI 组件一律从 `@multica/ui` 引入 Button/DropdownMenu 等原子组件，并通过 `cn()` 工具函数组合 className，避免内联样式。
- 字体与主题变量通过 `next/font/google` 导出 CSS 变量（`--font-inter`、`--font-mono`、`--font-serif`），在 layout 的 `html` className 中集中挂载。
