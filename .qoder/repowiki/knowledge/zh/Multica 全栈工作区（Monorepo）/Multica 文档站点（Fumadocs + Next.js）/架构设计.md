模块以 Next.js App Router 为运行时入口：`app/[lang]/layout.tsx` 通过 `fumadocs-ui` 的 `RootProvider`/`DocsLayout` 渲染文档骨架，并挂载自定义侧边栏脚注 `<DocsSettings>`；路由由 `[lang]` 动态段配合 `generateStaticParams` 生成 en/zh/ko/ja 四套静态参数。

内容层：`source.config.ts` 声明 `content/docs` 为文档根目录，`lib/source.ts` 用 `loader` 将 `@/.source`（由 `fumadocs-mdx` 在 postinstall 阶段从 MDX 生成）包装为带 i18n 的 source；`lib/i18n.ts` 配置 `hideLocale: 'default-locale'`，使英文路径无前缀而 zh/ko/ja 保留前缀。

请求层：`middleware.ts` 实现 basePath-aware 的 locale 重写——无语言前缀时 rewrite 到默认语言，显式 `/en/...` 重定向去除前缀，其他语言直接放行；匹配器排除 api、静态资源、sitemap.xml、robots.txt。

搜索层：`app/api/search/route.ts` 使用 `createFromSource` 暴露 Orama 搜索引擎，并为 zh/ja 注入字符级 tokenizer（CJK 按汉字/拉丁数字切分，日语扩展至平假名/片假名片段），韩语沿用英文 tokenizer。

组件层：`components/` 下均为可复用的文档增强组件（架构图、Mermaid、视频嵌入、编辑提示、社区链接等），UI 全部复用 `@multica/ui` 原子组件；`lib/locale-link.ts`、`lib/site.ts`、`lib/static-params.ts`、`lib/translations.ts` 提供本地化 URL 构造、站点元数据与翻译表。

依赖方向：页面 → lib（i18n/source/site）→ fumadocs-core；组件 → @multica/ui；不反向依赖业务 server 代码。
